## 📖 Descripción

Esta plataforma web interactiva ha sido desarrollada como recurso de apoyo para los estudiantes de la asignatura **Procesos Industriales** del periodo académico **2026-1** de la carrera de Ingeniería Industrial. 

El objetivo principal es proporcionar **herramientas de cálculo automatizadas** que complementen el aprendizaje teórico, permitiendo a los estudiantes:

- ✅ Resolver problemas de las guías de trabajo de forma interactiva
- ✅ Verificar sus cálculos manuales con resultados precisos
- ✅ Consultar tablas termodinámicas y de propiedades de fluidos
- ✅ Comprender las fórmulas y procedimientos de resolución
- ✅ Acceder a referencias manuales para exámenes sin internet

Cada módulo incluye un recuadro de **"Referencia para Búsqueda Manual"** que indica exactamente qué tabla, columna y fila consultar, cumpliendo con el requisito pedagógico de que los estudiantes puedan resolver problemas sin acceso a internet.

## ✨ Características Principales

- 🎨 **Diseño moderno y responsivo** con tema oscuro y colores institucionales
-  **6 módulos especializados** que cubren todo el contenido del curso
- 🧮 **Calculadoras interactivas** con validación de datos en tiempo real
- 📚 **Tablas termodinámicas completas** (Cengel & Boles, 9ª Edición) en formato JSON
- 📱 **Compatible con dispositivos móviles**, tablets y escritorio
- 🌐 **Funciona sin servidor** (solo HTML, CSS y JavaScript estático)
- 🔢 **Renderizado de fórmulas matemáticas** con MathJax
- 📖 **Instrucciones paso a paso** para resolución manual de problemas
