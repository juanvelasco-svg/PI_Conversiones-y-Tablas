TABLA F2: DIMENSIONES DE TUBERÍAS

Descripción

Esta tabla presenta las dimensiones estándar de tuberías de acero según la norma ASME B36.10M para tubos de acero al carbono e inoxidables.

Se incluyen los diámetros nominales (NPS), diámetros exteriores, espesores de pared según diferentes schedules (Sch 40, Sch 80, etc.) y diámetros interiores resultantes.

Cómo Usar Esta Tabla

  1. Identifique el Diámetro Nominal (NPS) de su tubería en pulgadas.
  2. Seleccione el Schedule (Sch) apropiado según la presión de trabajo.
  3. Obtenga el Diámetro Exterior (OD) que es fijo para cada NPS.
  4. Lea el Espesor de Pared según el Schedule seleccionado.
  5. Calcule o lea el Diámetro Interior (ID): ID = OD - 2 × Espesor.
  6. Use el diámetro interior para cálculos de flujo y pérdida de presión.

Fórmulas Relacionadas

  • Área de Flujo: \\( A = \\frac{\\pi \\times ID^2}{4} \\)
  • Velocidad del Flujo: \\( v = \\frac{Q}{A} \\)
  • Diámetro Interior: \\( ID = OD - 2 \\times t \\) donde t = espesor de pared

Notas Importantes

  • NPS = Nominal Pipe Size (pulgadas), DN = Diameter Nominal (mm)
  • El diámetro exterior (OD) es constante para cada NPS, independientemente del schedule
  • Mayor número de Schedule = mayor espesor de pared = menor diámetro interior
  • Sch 40 es el más común para aplicaciones generales
  • Sch 80 se usa para mayores presiones de trabajo
  • Para NPS ≤ 12, el NPS no coincide exactamente con el diámetro exterior
  • Para NPS ≥ 14, el NPS coincide con el diámetro exterior en pulgadas
