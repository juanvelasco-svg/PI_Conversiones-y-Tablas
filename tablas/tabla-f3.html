TABLA F3: RUGOSIDAD DE TUBERÍAS

Descripción

La rugosidad absoluta (ε) es una medida de las irregularidades en la superficie interior de una tubería. Este valor es fundamental para calcular el factor de fricción de Darcy-Weisbach usando el diagrama de Moody o la ecuación de Colebrook-White.

La rugosidad relativa se calcula como: \( \frac{\epsilon}{D} \) donde D es el diámetro interior de la tubería.

Fórmulas Relacionadas

  • Rugosidad Relativa: \( \text{Rugosidad Relativa} = \frac{\epsilon}{D} \)
  • Ecuación de Colebrook-White: \( \frac{1}{\sqrt{f}} = -2.0 \log_{10}\left(\frac{\epsilon/D}{3.7} + \frac{2.51}{Re\sqrt{f}}\right) \)
  • Ecuación de Swamee-Jain (explícita): \( f = \frac{0.25}{\left[\log_{10}\left(\frac{\epsilon/D}{3.7} + \frac{5.74}{Re^{0.9}}\right)\right]^2} \)

Notas Importantes

  • La rugosidad absoluta (ε) tiene unidades de longitud (mm o pies)
  • Para flujo laminar (Re < 2000), la rugosidad no afecta el factor de fricción
  • En flujo turbulento completamente desarrollado, el factor de fricción depende solo de la rugosidad relativa
  • Los valores de rugosidad aumentan con el tiempo debido a corrosión e incrustaciones
  • Para tuberías lisas (vidrio, plástico), ε ≈ 0
  • Use valores conservadores (mayores) para diseño cuando la condición de la tubería sea incierta

Ejemplo de Aplicación

Problema: Calcular la rugosidad relativa para una tubería de acero comercial nuevo de 6 pulgadas (DN 150, ID = 154.06 mm).

  1. Buscar rugosidad absoluta: ε = 0.045 mm (acero comercial nuevo)
  2. Obtener diámetro interior: D = 154.06 mm
  3. Calcular rugosidad relativa: \( \frac{\epsilon}{D} = \frac{0.045}{154.06} = 0.000292 \)
  4. Usar este valor en el diagrama de Moody o ecuación de Colebrook
